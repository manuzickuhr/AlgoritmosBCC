# 📚 Exercícios de Algoritmos - BCC IFC Blumenau

## 📖 Descrição

Este repositório foi criado para armazenar os exercícios desenvolvidos durante a disciplina de **Algoritmos**, no curso de **Bacharelado em Ciência da Computação (BCC)** do **IFC Blumenau**, cursado no primeiro semestre.

O objetivo é reunir todas as listas de exercícios realizadas ao longo da disciplina, utilizando a linguagem **Python**, com foco no desenvolvimento de lógica de programação, estruturas básicas e boas práticas de código.

---

## 🗂️ Estrutura das listas

Os exercícios estão organizados por listas, conforme os conteúdos vistos em aula:

### 🟢 Introdução à Programação em Python
- Lista 01 - Introdução à Programação Python  
- Lista 02 - Introdução à Programação Python  

### 🔵 Estruturas Condicionais
- Lista 03 - Comando Condicional  

### 🔁 Laços de Repetição
- Lista 04.1 - Laços de Repetição (Básico)  
- Lista 04.2 - Laços de Repetição  

### ⚙️ Funções
- Lista 05.1 - Funções (Básico)  
- Lista 05.2 - Funções (Parte 2)  

---

## 🎯 Objetivos do repositório

- Praticar lógica de programação  
- Desenvolver habilidades em Python  
- Consolidar os conceitos vistos em aula  
- Organizar exercícios de forma estruturada  
- Acompanhar a evolução ao longo da disciplina  

---

## 📚 O que foi aprendido

Durante a disciplina e resolução das listas, foram trabalhados conceitos como:

- Variáveis e tipos de dados  
- Entrada e saída de dados  
- Operadores lógicos e matemáticos  
- Estruturas condicionais (`if`, `else`, `elif`)  
- Estruturas de repetição (`for`, `while`)  
- Criação e utilização de funções  
- Modularização de código  
- Resolução de problemas lógicos
